    Workflow

    1. Open an image (or the sample). It is analysed with the defaults.
    2. Inspect: zoom, pan, toggle layers and compare with the original.
    3. Adjust settings on the left, then Run analysis.
    4. Export the cell table, full report or figures.

    Layers

    Original
    Your image, unmodified.
    Processed
    What segmentation saw: channel, smoothing and background correction applied, linearly stretched for display. Measurements always use the original intensities.
    Outlines
    Cell boundaries, coloured by brightness class (Low, Medium, High). Okabe–Ito colours are distinguishable with colour-vision deficiency.
    Mask
    Each segmented cell filled with its own colour.
    Ground truth
    Validate mode only: the true cell outlines, in purple.

    Method

    Otsu (or chosen) threshold held above a robust noise floor, then a marker-controlled watershed splits touching cells. Shape and intensity are measured per cell on the raw signal. Full details: docs/METHODS.md.
